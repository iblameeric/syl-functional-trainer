# SYL TS 2.0 Trolleys: 2:1 Functional Trainer Setup

A step-by-step guide to turning four SYL Fitness TS 2.0 trolleys and a 6-post rack into a 2:1 plate-loaded functional trainer with a 1:1 lat pulldown and a Smith machine, using one cable loop per side.
